Подключим ваш Direct.

Для реального запуска подключите Supabase, Cloudflare, почту и приложение Meta. Вход в рабочее пространство разрешён только команде после email-кода и MFA.

Полная техническая инструкция лежит в проекте: docs/SETUP.md. Здесь — порядок действий для владельца.

01 · Supabase

  1. Создайте проект и примените все миграции из supabase/migrations.
  2. Отключите публичную регистрацию, включите TOTP MFA и настройте email-коды по инструкции. Администратор применяет список приглашений из приватного файла вне репозитория.
  3. Опубликуйте шесть Edge Functions и задайте серверные секреты. Настройте Resend для писем и Turnstile для формы входа. Токены Supabase остаются на сервере.
  4. Настройте защищённый запуск очереди из supabase/setup/schedule.sql.

02 · Фронтенд

Используйте Cloudflare Pages с Pages Functions: сборка npm run build, каталог dist. Деплой через Git integration или Wrangler из корня проекта. Обычная загрузка dist через dashboard не включает папку серверных функций.

Публичные переменные: VITE_TURNSTILE_SITE_KEY и VITE_ENABLE_DEMO=false. Серверные bindings Pages — SUPABASE_URL и GATEWAY_SECRET; секрет шлюза должен совпадать с Supabase. Первым входит владелец и настраивает MFA, затем второй участник команды.

Notion подходит для страницы помощи и встраивания ссылки на приложение. Он не запускает React-приложение и его сервер. Vercel требует тарифа с разрешённым коммерческим использованием.

03 · Meta и Instagram

  1. Переведите Instagram в Business или Creator.
  2. Создайте приложение Meta с Instagram API и Instagram Login. Добавьте свой аккаунт для тестирования, примите приглашение и настройте разрешения. Для рабочего webhook нужны Live-режим, Advanced Access и проверка бизнеса Meta. Тип Instagram-аккаунта может быть Business или Creator.
  3. OAuth callback находится на домене приложения: /api/instagram-callback. В настройках webhook добавьте адрес Supabase …/functions/v1/instagram-webhook и ваш verify token.
  4. Опубликуйте собственные страницы политики конфиденциальности и удаления данных. Шаблоны находятся в docs.
  5. В ReplyFolio откройте «Настройки → Подключить Instagram» и пройдите официальный вход.

04 · Проверка перед запуском

Замените демонстрационные ссылки своими материалами, включите сценарий и проверьте с другим тестовым аккаунтом: ключевое слово в Direct, комментарий, ответ на него, сбор заявки и передачу менеджеру. Первое сообщение после комментария не даёт права продолжать переписку без ответа пользователя.

Проверка на реальном аккаунте обязательна: локальный симулятор не подтверждает доступ Meta и доставку Instagram.
