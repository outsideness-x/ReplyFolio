GrowthThread

Connect your Direct.

GrowthThread uses Supabase, Cloudflare Pages, Resend and your Meta app. Workspace access requires a verified team email and an authenticator code.

The full technical guide is in the project: docs/SETUP.md. Follow these steps when setting up a new environment.

01 · Supabase

  1. Create a project and apply every migration in supabase/migrations.
  2. Close public registration, enable TOTP MFA and configure email codes. An administrator provisions team invitations from a private file outside the repository.
  3. Deploy the six Edge Functions and set their server secrets. Configure Resend for sign-in emails and Turnstile for browser verification. Supabase tokens stay on the server.
  4. Configure the protected job runner using supabase/setup/schedule.sql.

02 · Frontend

Use Cloudflare Pages with Pages Functions. Run npm run build and deploy dist with Wrangler from the project root. Uploading static files through the dashboard does not include the server functions.

The public settings are VITE_TURNSTILE_SITE_KEY and VITE_ENABLE_DEMO=false. Server bindings are SUPABASE_URL and GATEWAY_SECRET. The gateway secret must match Supabase. The owner signs in and sets up MFA first.

Notion can host a help page or a link to the workspace. It cannot run the React app and its server. Vercel requires a plan that permits commercial use.

03 · Meta and Instagram

  1. Switch Instagram to a Business or Creator account.
  2. Create a Meta app with the Instagram API and Instagram Login. Add your account for testing, accept the invitation and configure permissions. Live webhooks require Live mode, Advanced Access and Meta business verification. Both Business and Creator accounts are supported.
  3. The OAuth callback is on your app domain: /api/instagram-callback. Add your Supabase webhook endpoint …/functions/v1/instagram-webhook and verify token to Meta.
  4. Publish your privacy policy and data deletion pages. Templates are in docs.
  5. In GrowthThread, open Settings → Connect Instagram and use the official sign-in screen.

04 · Before launch

Add your own resources, enable a flow and test with another test account: Direct keywords, comments, replies, lead capture and a handoff to your team. An initial private reply to a comment does not allow further messages until the person responds.

Test with a live account. The local simulator does not verify Meta access or Instagram delivery.
