# GrowthThread

Закрытый кабинет команды для автоматизации Instagram Direct в EdTech-бизнесе. Без ИИ. Минималистичный интерфейс, светлая и тёмная темы, поиск ⌘K, сценарии, материалы, переписка и заявки.

GrowthThread объединяет диалоги и аналитику. Подготовлены разделы «Аналитика приложения» (iOS/Android, D1/D7/D30, когорты), «Аналитика Instagram» и «Взаимосвязи». Пока это UI previews со статусом «Скоро»: данных, расчётов и новых подключений нет.

**Опубликовано:** [growththread.pages.dev](https://growththread.pages.dev). Интерфейс, письма и сообщения об ошибках — на английском. В production демо отключено.

Supabase настроен: десять миграций, шесть Edge Functions, приватные приглашения команды, TOTP и защищённый Cron. Pages Functions и Turnstile подключены; preview не получает серверные секреты. Resend подтвердил `auth.orot.study`, отправка использует ограниченный ключ и обязательный TLS.

Первый настоящий email/MFA-вход владельца успешно проверен: фактор закреплён, защищённая сессия активна, рабочее пространство создано. **Instagram пока не подключён:** создание приложения Meta и доставка в Instagram ещё требуют проверки.

## Запуск

Node.js 24+:

```sh
npm ci
npm run dev
```

Стартовая страница: http://127.0.0.1:5173/. Рабочая демонстрация: http://127.0.0.1:5173/?demo=1. Демо использует только вымышленные данные в браузере. В production оно отключено по умолчанию.

## Доступ

Вход по одноразовому коду из email. Участник приватного списка приглашений проходит обязательный TOTP MFA; владелец первым создаёт общее пространство команды. Посетителю вне команды после подтверждения email предлагается добровольный лист ожидания.

Браузер получает только непрозрачную HttpOnly cookie. Supabase JWT и refresh token остаются зашифрованными на сервере. Запросы идут через подписанный Cloudflare Pages Functions шлюз; прямой доступ браузерных ролей к таблицам и служебным RPC закрыт. Адреса команды хранятся вне этого репозитория.

## Возможности

- Диалоги, ручной ответ и пауза бота.
- Сценарии по сообщениям и комментариям: кнопки, условия, материалы, контакты, теги, задержки и передача менеджеру.
- HTTPS-ссылки и публичные PDF, заявки и CSV.
- Симулятор на том же движке, который использует сервер.
- Официальный OAuth Instagram, подписи webhook, приватная очередь, ограничения окна ответа, шифрование и обновление токенов.

## Проверка

```sh
npm test
npm run build
npm run check:edge
npx playwright install chromium
npm run test:e2e
npm run format:check
npm run check:privacy
```

48 unit/integration тестов и 18 браузерных проверок. Проверка приватности сканирует файлы, историю Git и сборку. Реальные секреты и адреса команды не выводятся.

## Git

Отдельный локальный репозиторий на main, remote не задан. Каждое самостоятельное изменение — отдельный коммит. Production размещён в Cloudflare Pages и Supabase; приватное provisioning находится вне репозитория.
